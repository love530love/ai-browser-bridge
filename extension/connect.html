& 'K:\PythonProjects5\AI-Browser-Bridge\agent.ps1' tools

K:\PythonProjects5\AI-Browser-Bridge\AGENT-QUICKSTART.md

支持 MCP 的 Agent

在客户端添加本机生成的 MCP 配置，即可调用浏览器工具：

K:\PythonProjects5\AI-Browser-Bridge\.local\mcp-config.json

上述是当前电脑的安装路径。迁移后使用实际项目路径。无本机工具通道的纯聊天窗口，需要其宿主先提供连接能力。
