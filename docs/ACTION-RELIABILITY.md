# 浮层、坐标与交易结果可靠性

2026-10-24：根据用户提供的 VeryAI 操作记录审议，未在真实租用页面重放操作。记录中的历史遮挡根因尚未通过截图、命中测试与同时间布局数据确证。

## 当前实现

- `browser_click` 检查中心点命中，不能绕过遮挡。
- `browser_dismiss_overlay` 点击指定关闭控件并等待消失，不删除 DOM 背板。
- `browser_action` 使用当前视口 0..1000 归一化坐标，检查 URL 与视口可用性；同 URL 下布局变化尚无快照绑定保障。
- `browser_failure_help` 对遮挡返回截图、命中与坐标单位诊断；对 attemptedAction 中明确描述的租用、续租、付款返回 `transactionOutcome: unknown`、所需凭据及禁止自动重放标志。这是确定性建议，不会调用网站、判定订单结果或执行恢复动作。仅传通用工具名不能推断业务意图。
- MCP 初始化加载的操作契约要求核对容器、产品、数量、计费与价格，禁止按标签/几何列表顺序配对，禁止以库存变化、余额变化或按钮已点击作为订单完成证据。

## 验证边界

单元测试覆盖遮挡解释、租用结果未知、错误文本不能改变动作意图、离线诊断及禁止写重放。没有执行真实付费、租用、开关机操作，没有证明本次 VeryAI 页面已经修复。

更新契约需 MCP 客户端重新连接；服务端诊断变更需服务加载新代码。本次未修改扩展，无需因这些变更重新加载 Chrome 扩展。源码推送不代表正在运行的进程已升级。

## 下一步硬性保障与验收

1. 将截图、视口尺寸、滚动位置和目标命中信息绑定到动作准备结果；布局过期返回重新观测，不派发点击。
2. 为同名按钮增加可见对话框和容器约束；使用遮挡、固定列副本、隐藏 modal、异步换产品的本地夹具验证。
3. 增加显式业务后置条件及结果 `confirmed / unknown / rejected`；未确认不触发第二次提交。通用 UI 条件验证不能替代订单后端事实。
4. 在无真实费用的测试页验证从发现错误配置、重新定位到结果读取的完整流程，再进行授权现场验收。

这些项目仍待实现，不能作为现有能力宣传。客户端契约不能强制任意模型遵守，也不能保证第三方网站永不变化。
