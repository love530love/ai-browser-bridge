# 0.1.1 · 默认所有网站

用户明确要求默认允许所有网站后实现此更新。

- Chrome host 权限改为 `http://*/*` 与 `https://*/*`。
- 旧配置未设置 allSites 时默认 true。配对密钥、端口、暂停状态及原指定网站列表均保留。
- 所有网站模式覆盖标签列表、打开、导航、读取、填写、点击与截图；取消勾选后重新采用指定列表。
- Chrome 内部页、本地文件和浏览器保护页面不属于可任意操作的范围。
- 面板连接状态通过事件更新，避免已连接时仍停留“连接中”；没有增加状态轮询或模型调用。
- 原有后台服务与新扩展协议兼容，无需重启服务。

验证：服务测试 6 项；真实 Chromium 扩展测试增加默认值、未列出网站上的读写、跨站点击/导航以及恢复指定列表的检查。最终结果以 `output/playwright/e2e-report.json` 为准。

本次修改前，认证的实际本机服务状态为 `connected: true`。这证明旧扩展已连通；新版全网站权限须在日常 Chrome 重新加载扩展后才生效。

加载本项目 extension 目录的用户：Chrome 扩展页 → 重新加载 → 打开面板 → 确认默认勾选 → 保存并连接。如果使用另一个解压目录，请先更新该目录中的扩展文件。
