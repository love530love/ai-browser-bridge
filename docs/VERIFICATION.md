## 调试中发现并处理

1. Node fetch 会改写 Host，原 Host 拒绝测试未真实发送异常头。改用原生 HTTP 客户端后测试通过。
2. Chrome executeScript 不可靠传播注入脚本抛错。增加结构化错误封装后，过期引用确实返回工具错误，不再误报成功。
3. 冷启动时观察到一次连接立即断开。连接逻辑增加 epoch 保护，避免并发异步连接覆盖；修改后的完整服务与浏览器测试通过。跨机器、浏览器升级和长时间休眠恢复仍需持续验证。
